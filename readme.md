# Pesquisas em Red Team

Repositório de **provas de conceito (PoCs)** e pesquisas em segurança ofensiva, mantido por [Fernando Bortotti](https://github.com/fernandobortotti).

O foco aqui é o **código**: exploits, scripts e demonstrações práticas que comprovam falhas de segurança. A análise técnica aprofundada — o "porquê" e o "como" por trás de cada PoC — quando existir, fica no blog:

- 📝 **Blog:** [Crônicas de Hacknagem](https://fernandobortotti.github.io/artigos/)
- 👤 **Perfil:** [github.com/fernandobortotti](https://github.com/fernandobortotti)

> Nem toda PoC deste repositório terá um artigo correspondente no blog, e vice-versa.

## Propósito

Este é um repositório de pesquisa: um caderno público de provas de conceito em áreas como web, mobile e cloud (AWS), bug bounty, análise de vulnerabilidades e CVEs.

O **objetivo é compartilhar conhecimento e aumentar a segurança dos sistemas**. Entender como uma falha é explorada é o primeiro passo para corrigi-la e para construir defesas melhores.

## Organização

Cada pesquisa fica em seu próprio diretório, nomeado pela classe de vulnerabilidade ou pelo alvo. Por exemplo:

```
pesquisas/
├── ssrf/     # PoCs de Server-Side Request Forgery
└── ...
```

Quando houver um artigo relacionado, o diretório trará o link para o conteúdo no blog.

## Áreas de interesse

- Segurança de aplicações web e mobile
- Cloud Security (AWS)
- Bug bounty e pesquisa de CVEs
- Análise de vulnerabilidades e desenvolvimento de exploits
- Análise estática de malware e CTFs
